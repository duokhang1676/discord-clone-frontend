# Hướng dẫn chạy ứng dụng

## 1. Cài đặt Python packages cho Backend

```bash
pip install -r requirements.txt
```

## 2. Khởi động Backend Server (Flask)

Mở terminal và chạy:

```bash
cd backend
python app.py
```

Backend sẽ chạy trên: **http://127.0.0.1:5000**

## 3. Khởi động Frontend Server (Node.js)

Mở terminal mới và chạy:

```bash
npm start
```

Frontend sẽ chạy trên: **https://localhost:3000**

## 4. Sử dụng

1. Truy cập: `https://localhost:3000` hoặc `https://192.168.1.6:3000`
2. Đăng ký tài khoản mới
3. Đăng nhập
4. Bắt đầu voice chat!
